# Taz: Wanted Native (Linux / Vulkan Port)

A modern Linux and Vulkan C++ implementation reverse-engineered from the 2002 PC game *Taz: Wanted*.

## Legal Disclaimer
This repository contains **no game assets, copyrighted binaries, or original audio/visual data**. To build and run the executable, you must provide your own legally owned copy of *Taz: Wanted* to extract game data files (`.pc` archives).
